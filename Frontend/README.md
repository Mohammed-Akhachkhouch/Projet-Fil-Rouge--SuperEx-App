# SuperEx (Super Market Express) – Fil Rouge Project

## 1️⃣ Project Overview
**SuperEx** is a full-stack mobile application that allows users to order supermarket products, pay online, and have them delivered to their home at a chosen time.  
This project is developed as part of the **Jobintech – Fil Rouge** training program.

**Objectives:**
- Build a functional mobile application (React Native + Expo)
- Build a secure backend (Node.js + Express + TypeScript + PostgreSQL/Prisma)
- Implement authentication, order tracking, and product management
- Deploy the application using Docker

---

## 2️⃣ Main Features

### 👤 User Features
- Sign up / Login (email or phone)
- Browse and search products
- Manage shopping cart
- Online payment (Stripe / PayPal)
- Choose delivery address and time slot
- Track orders
- Rate products and service

### 🛠️ Admin Features
- Manage products and categories (CRUD)
- Manage orders
- Update order status

---

## 3️⃣ Technical Stack

**Mobile Frontend:**
- React Native + Expo
- Expo Router / React Navigation
- Zustand (state management)
- Axios (API requests)
- Expo SecureStore (secure token storage)

**Backend:**
- Node.js + Express
- TypeScript
- Prisma ORM (PostgreSQL)
- JWT authentication
- Swagger (API documentation)

**Deployment:**
- Docker / Docker Compose
- Railway or Render (hosting)
